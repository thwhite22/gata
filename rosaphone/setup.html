Rosaphone setup

Putting Rosie’s music machine on her eye gaze device — about 5 minutes.

What's in this folder

index.htmlRosaphone itself — the whole app in one file, works offline. Rosaphone.batStarts it full-screen with sound and microphone pre-allowed. This is the one to launch. Create-Desktop-Shortcut.batPuts a Rosaphone icon on the desktop. Try-the-sounds.batTap-only sound check (speakers, volume, mic) — no eye gaze needed. Rosaphone-windowed.batSame app in a normal window, for trying things out. enable-autoplay.regOptional, needs admin — see step 5. setup.htmlThis guide. README.md has the deep details.

Install

  1. Copy this whole folder onto the device — for example to Documents\Rosaphone or C:\Rosaphone (USB stick, OneDrive, however you like). Keep the files together.
  2. Double-click Create-Desktop-Shortcut.bat. A Rosaphone icon appears on the desktop. Double-click it: Rosaphone opens full-screen and the music is ready with no taps needed — the launcher pre-allows sound and the microphone. (The mic flag auto-accepts permission prompts in that window; the window only ever opens Rosaphone.)
  3. Check the sound with Try-the-sounds.bat — tap each instrument, watch the meter. If the meter moves but you hear nothing, the device is muted, not broken.
  4. Add it to her AAC software so she can open it herself: make a button whose action opens a program and point it at Rosaphone.bat (not index.html, so the launcher's settings apply).
    • TD Snap: Edit → select a button → add the Open App / Open Program action.
    • Communicator 5: button action Run Program.
    • Grid 3: command Open program.
    The action name varies a little by version — it's always in the button-actions list.
  5. Optional (admin): if Rosaphone will ever be opened without Rosaphone.bat (e.g. a browser bookmark), right-click enable-autoplay.reg → Merge so music can still start with no tap.

Eye gaze notes

  • Rosaphone expects gaze to move the pointer (Tobii Computer Control / Windows Control). Resting her gaze on a card fills a ring; when it completes, the instrument switches. She must look away before the same card can fire again.
  • If her Tobii is set to click after a dwell, open the gear ⚙ in Rosaphone and set Gaze dwell → Off so the two dwells can't double-fire.
  • Look time (0.6–2.5 s), song speed, her Record loop length (1/2/4 bars) and volume are all in the gear menu — it opens by tap only, so she can't reach it by gaze.
  • Her song choice, mix, settings and her recorded loop are saved on the device and come back after a restart.

Handy to know

To…Do this
Leave full-screenPress Alt+F4 (attach a keyboard or use the touch keyboard).
Start on a chosen songEdit Rosaphone.bat: change the APP line to set "APP=file:///%~dp0index.html?song=island" (songs: night, sunny, island, star, dragon; also &mix=drums,bass, &tempo=slow, &loop=1, &dwell=1200).
Launch from another app (e.g. Rosie's Rosetta Stone)Have it run Rosaphone.bat, or open the file URL above with any parameters.
Update RosaphoneReplace index.html (and soundcheck.html) with newer ones. Her recordings and settings survive.
Keyboard / switch access1–8 toggle instruments, R record, Space stop all, Tab+Enter for scanning.

If something's not right

SymptomFix
No soundRun Try-the-sounds.bat. Meter moving = device muted / volume keys down. Meter still = make sure you launched via Rosaphone.bat, or tap the screen once.
Record says "Mic blocked"Launch via Rosaphone.bat (auto-allows), or click Allow once on the browser's mic prompt.
Gaze moves the pointer but nothing switchesCheck the gear ⚙: Gaze dwell On, and try a longer look time. If the Tobii itself clicks after a dwell, her gaze click works like a tap — set Gaze dwell Off instead.
Cards flicker / toggle twiceTobii dwell-click AND Rosaphone dwell are both on — turn one off (gear ⚙ → Gaze dwell Off).
